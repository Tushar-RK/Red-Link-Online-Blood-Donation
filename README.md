# Red Link - Online Blood Donation

A simple and responsive website for blood donation awareness and donor connectivity.

## 📖 About

Red Link is a web platform designed to facilitate blood donation by connecting potential donors with those in need. The website provides information about blood donation and serves as a bridge between donors and recipients.

## 🛠️ Installation

1. **Clone the repository**
```bash
git clone https://github.com/Tushar-RK/Red-Link-Online-Blood-Donation.git
cd Red-Link-Online-Blood-Donation
```

2. **Run the project**
- Simply open `index.html` in your web browser
- For best results, use a local server like Live Server extension in VS Code
